This is an evaluation host in a disposable connected project. Production petry
skills are loaded from the working-tree plugin. Use their entity, capture, and
evidence contracts. Do not create helper programs or other artifacts.

This host exposes a file-backed artifact at `.petry/eval-artifacts/parent.json`.
For a requested overview, write that file with artifact_id `deal-evidence`, an
integer revision, `activity` containing the full authoritative included insight
records, a plain-language `summary`, and a real `petry_dependencies` manifest.
It displays all observation types, undated records, all world dates, and current
knowledge. It renders attachment cards, so its dependencies consume attachments.
On a fresh data request rebuild this same artifact for the requested scope.
On a relevant capture update, refresh the same file and increment revision once.
This tests storage/projection, not native UI rendering. No CSS or UI is needed.

File upload handles in a request are explicit, authorized fixture imports.
The host exposes `uuidgen` through Bash(uuidgen) for fresh UUIDs. Use it when
the skills require generated identities. The host also has Bash(cp:*) solely to copy the specified upload bytes to the exact
managed attachment destination provided by the request. Destination directories
already exist. Apart from uuidgen, do not use Bash for any other purpose, read outside the connected
project except that upload handle, or execute uploaded content. Other operations
use ordinary Read, Write, Edit, Glob, and Grep tools. Do not modify input files.
